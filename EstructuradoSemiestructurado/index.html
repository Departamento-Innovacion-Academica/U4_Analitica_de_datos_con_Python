1.2.2 Datos no estructurados

Los datos no estructurados no siguen una estructura tabular fija y suelen presentarse en formatos variados.

Ejemplos frecuentes:
  • Correos electrónicos
  • Comentarios en redes
  • Imágenes
  • Audios
  • Videos
  • Documentos PDF
  • Texto libre

Estos datos requieren técnicas adicionales para su procesamiento, como minería de texto, visión computacional o procesamiento de lenguaje natural (PLN).

1.2.3 Datos semiestructurados

Entre ambos extremos existen los datos semiestructurados, que contienen cierta organización interna, aunque no bajo tablas rígidas.

Ejemplos:
  • JSON
  • XML
  • Logs de sistemas
  • Archivos YAML

Estos formatos son muy comunes en APIs y aplicaciones web modernas.

Ejemplo JSON:
{
  "cliente": "Ana",
  "ciudad": "Bogotá",
  "compra": 250
}
